# 🇰🇭 Telegram Smart Assistant Bot (Hub 2.0)

Telegram Bot ជំនួយការឆ្លាតវៃពហុមុខងារ (Multi-purpose Smart Assistant Hub) បង្កើតឡើងយ៉ាងពិសេសសម្រាប់អ្នកប្រើប្រាស់នៅប្រទេសកម្ពុជា 🇰🇭។

---

## 🌟 មុខងារសំខាន់ៗ (Key Features)

### 1. 📥 All-in-One Media Downloader & Audio Extractor
- **ទាញយកវីដេអូកម្រិតច្បាស់ (HD Video):** គាំទ្រ TikTok (Watermark-Free), YouTube, Facebook Reels/Videos, Instagram, X/Twitter។
- **🎵 ទាញយកសំឡេង MP3:** បម្លែងវីដេអូទៅជា file សំឡេង MP3 ដោយស្វ័យប្រវត្តិ។
- **🖼️ ទាញយករូប Cover HD:** ទាញយករូប Thumbnail/Cover កម្រិតច្បាស់ខ្ពស់ពីវីដេអូ។
- **⚡ Direct Web Link:** មាន Link សម្រាប់មើល ឬ Download ផ្ទាល់ភ្លាមៗដោយមិនបាច់រង់ចាំ Telegram Upload។

### 2. 💰 ព័ត៌មានសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុប្រចាំថ្ងៃនៅកម្ពុជា (Cambodia Daily Finance)
- **💱 អត្រាប្តូរប្រាក់បច្ចុប្បន្ន (Live Exchange Rates):** USD, KHR (រៀល), THB (បាត), EUR, CNY។
- **🪙 តម្លៃមាសនៅកម្ពុជា (Gold Prices):** គណនាតម្លៃមាសជា **តម្លឹង** (Damlung: 37.5g) និង **ជី** (Chi: 3.75g) តាម Spot Market អន្តរជាតិ និងប្រាក់រៀល។
- **⛽ តម្លៃប្រេងឥន្ធនៈ (Fuel Prices):** តម្លៃផ្លូវការកំណត់ដោយក្រសួងពាណិជ្ជកម្មកម្ពុជា (សាំងធម្មតា EA92, ស៊ុបពែរ EA95, ម៉ាស៊ូត)។
- **🧮 មុខងារគណនាប្តូរប្រាក់រហ័ស:** `/convert 100 USD KHR` ឬ `/convert 50000 KHR THB`។

### 3. 🤖 បច្ចេកវិទ្យា AI ជំនាន់ថ្មី (Gemini 2.5 Flash & GPT)
- **🎙️ Voice Message AI:** អ្នកប្រើប្រាស់គ្រាន់តែសង្កត់ផ្ញើសារសំឡេង (Voice Note) ជាភាសាខ្មែរ ឬអង់គ្លេស ➔ AI នឹងស្តាប់យល់ និងឆ្លើយតបមកវិញភ្លាមៗ!
- **📷 Vision OCR & Homework Solver:** ផ្ញើរូបភាពឯកសារ វិក្កយបត្រ ឬលំហាត់ ➔ AI ជួយស្រង់អក្សរ បកប្រែភាសា និងដោះស្រាយលំហាត់មួយជំហានៗ។
- **💬 Continuous AI Chat Mode (`/aimode`):** បើក Chat Mode ដើម្បីជជែកឆ្លើយឆ្លងជាប់គ្នាដូច ChatGPT ពិតៗ ដោយមិនបាច់វាយ `/ask` រាល់ដងឡើយ រួមទាំងមាន Memory ចងចាំការសន្ទនា។

### 4. ⏰ ការរំលឹក និងគ្រប់គ្រងកិច្ចការផ្ទាល់ខ្លួន (Personal Reminders & Tools)
- **🔔 Custom Reminders:** បញ្ជាឱ្យ Bot រំលឹកម៉ោងណាមួយយ៉ាងងាយស្រួល៖
  - ឧ. `/remind 08:30 ទៅជួបភ្ញៀវនៅហាងកាហ្វេ`
  - ឧ. `/remind 15m ឆុងកាហ្វេ និងពិនិត្យ Email`
  - ឧ. `/remind 2h បញ្ចប់របាយការណ៍ការងារ`
- **🔲 QR Code Generator & KHQR Reader:**
  - បង្កើត QR Code ភ្លាមៗ៖ `/qr https://t.me/Researchmap_bot`
  - អាន QR Code / KHQR ធនាគារ៖ ផ្ញើរូបភាព QR ចូលក្នុង Bot ដើម្បី Decode ទិន្នន័យ។

### 5. 🌤️ អាកាសធាតុ ៥:០០ ព្រឹក & 🗓️ ប្រតិទិនបុណ្យជាតិ ៤:០០ ព្រឹក
- **🌅 ដំណឹងអាកាសធាតុ ៥:០០ ព្រឹក:** ផ្ញើរបាយការណ៍អាកាសធាតុប្រចាំថ្ងៃនៅទីតាំងផ្ទាល់ខ្លួនរាល់ព្រឹក (តាម GPS ឬជ្រើសរើសខេត្ត)។
- **⏰ ដំណឹងបុណ្យជាតិ ៤:០០ ព្រឹក:** ជូនដំណឹងស្វ័យប្រវត្តិនាពេលទៀបភ្លឺរាល់ថ្ងៃឈប់សម្រាកបុណ្យជាតិផ្លូវការនៅកម្ពុជា។

### 6. 👥 Group Support & 📢 Admin Broadcast Panel
- **Telegram Group Support:** អាច Add Bot ចូល Group ក្រុមការងារ ឬគ្រួសារបានយ៉ាងរលូន។
- **Admin Broadcast:** អ្នកគ្រប់គ្រង (Admin ID) អាចផ្ញើសារប្រកាសដំណឹង `/broadcast <សារ>` ទៅកាន់ User ទាំងអស់ក្នុងពេលតែមួយ។

| `/status` | ពិនិត្យស្ថានភាពគណនី និងការកំណត់ទាំងអស់ |
| `/help` | មើលការណែនាំអំពីរបៀបប្រើប្រាស់ |

## 🚀 របៀបដំណើរការ (Local Setup)

```bash
# 1. Clone repository
git clone https://github.com/cheat870/assistant_bot.git
cd assistant_bot

# 2. Install requirements
pip install -r requirements.txt

# 3. Setup .env file
# TELEGRAM_BOT_TOKEN="your_bot_token"
# GEMINI_API_KEY="your_gemini_key" (Optional for AI)

# 4. Run bot
python main.py
```
